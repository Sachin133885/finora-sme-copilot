# Contributing to Finora

Discuss major changes with The Fantastic Five before implementation. No specific engineering ownership has been assigned in the supplied registration form.

1. Create a branch from the current repository history; keep commits focused and avoid force-pushing main.
2. Use Node 24 and the documented npm/build/test commands.
3. Preserve integer-fen amounts, business isolation, explicit posting/paid confirmation, settlement/reversal rules, permissions, AI consent and server-only secrets.
4. Keep English/Simplified Chinese copy consistent. Respect reduced motion and current light/dark behavior.
5. Run the 33-suite regression set and rebuild offline outputs when application inputs change. Distinguish simulated DOM checks from actual browser checks.
6. Use synthetic fixtures, never personal financial data or credentials. Do not commit the registration workbook, identity attachments, databases or real environment files.
7. Document observed limitations. Do not fabricate screenshots, live-model verification or performance figures.

No project-wide license is specified; contribution and reuse rights should be agreed with the team. Third-party license notices must remain intact.
